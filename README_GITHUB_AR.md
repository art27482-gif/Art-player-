# ART Player - بناء APK من GitHub

بعد رفع المشروع إلى GitHub:
1. افتح تبويب Actions.
2. اختر Build ART Player APK.
3. إذا لم يبدأ تلقائياً اضغط Run workflow.
4. انتظر حتى تصبح المهمة خضراء.
5. افتح نتيجة التشغيل ثم قسم Artifacts وحمّل ARTPlayer-debug.
6. فك الضغط عن الملف على الهاتف وستجد app-debug.apk.

لا يحتاج هذا المشروع إلى Android Studio أو كمبيوتر للبناء؛ GitHub Actions يقوم بالبناء على خوادمه.
